# Contributing (Local)

## PR-only workflow (Policy)
- **No direct commits** to the canonical repo: `</srv/alms`
- All changes must be made on **feature branches** in agent workspaces
- Submit changes via a **PR summary** in chat for review/merge

### Canonical repo
- Location: `</srv/alms`
- Default branch: `main`

### Agent workflow
1) Clone canonical into your workspace
2) Create a feature branch
3) Commit locally
4) Send PR summary (diff + rationale)
5) Merge into canonical only after approval

## Rationale
Keeps the canonical repo stable and makes parallel work safe.
